# varchar playground

A single-screen web app for [`varchar`](../README.md): run SQL against a database that is one
string, and watch both the string and the regex that scans it.

The engine is the real `varchar` crate compiled to `wasm32-unknown-unknown`. There is no server
side and no persistence — the database lives in WebAssembly memory for the lifetime of the tab.

## Layout

```
web/
  wasm/              standalone wasm-bindgen crate wrapping the core (not a workspace member)
  src/
    App.jsx          panes, dialogs and all the state
    components/      Console, ScanPane, ResultPane, LogPane, StringDock, Topbar, dialogs, ui
    lib/             db (wasm boot + statement splitting), bytes, pattern, presets, csv
    styles/          tokens.css (design system, unmodified) + app.css
    wasm/            generated by wasm-pack, gitignored
  index.html         Vite entry: document shell and the SVG icon sprite
  dist/              build output, gitignored — what Cloudflare serves
  wrangler.jsonc     static-assets-only Cloudflare Worker
```

Preact + Vite. `web/wasm` declares its own empty `[workspace]` so the published crates, their
lints and their CI gates are unaffected by the browser adapter.

## Develop

```console
pnpm install
pnpm run dev        # wasm-pack build, then vite
pnpm run build      # wasm-pack build, then vite build -> dist/
pnpm run preview    # serve dist/
```

`src/lib/db.js` imports the `.wasm` through Vite's `?url` so it is emitted as a hashed asset and
`init({ module_or_path })` fetches it — the default `import.meta.url` resolution inside the
wasm-bindgen glue does not survive bundling.

## Deploy

```console
pnpm run deploy     # build, then wrangler deploy
```

The Worker serves `dist/` as static assets; nothing runs on the edge.

## What the adapter exposes

`wasm/src/lib.rs` keeps one `Database` alive and returns a JSON envelope per call:

| Method | Purpose |
| --- | --- |
| `db.exec(sql)` | Execute one statement. `SELECT` results also carry the compiled pattern and the byte ranges it matched. |
| `db.explain(sql)` | Compile a `SELECT` to its pattern without executing it. |
| `db.load(blob)` | Validate and adopt a persisted string; the current database is untouched if it is rejected. |
| `db.dump()` / `db.reset()` | Read the authoritative string, or drop everything. |

Match ranges are UTF-8 byte offsets into the blob, which is why `src/lib/bytes.js` slices the
encoded bytes rather than the JS string. `INTEGER` values travel as strings, since the column is
signed 64-bit and JSON numbers lose precision past 2^53.
